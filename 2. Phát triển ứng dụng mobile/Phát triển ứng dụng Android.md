# Android

### Giới thiệu

Android là một hệ điều hành mở, hoạt động trên các thiết bị di động (bao gồm cả TV, ô tô,...) dựa trên nhân Linux.

**Chức năng**:
- Hỗ trợ các thao tác về chạm (Tough gestures): Vuốt (swipping), Chạm (tapping), Chụm (Pinching).
- Hỗ trợ bàn phím ảo (Virtual keyboard).
- Hỗ trợ Bluetooth, USB,...

**Sensor**:
- Dùng để phát hiện hành vi của người dùng và phản hồi.
- Những hành vi này không nhất thiết phải tương tác với thiết bị.

**Android app**:
- Là tập hợp của các giao diện có thể được tương tác, chạy trên Android.
- Được viết bằng Java và XML.
- Được phát triển thông qua Android Software Developer Kit (SDK).
- Được thực thi bởi Anroid Runtime Virtual machine (ART).

### Kiến trúc Android

1. **System apps and User apps**: Các ứng dụng hệ thống và ứng dụng người dùng.
2. **Java API Framework**: Cung cấp cách thức để sử dụng các tính năng của Android (API). Các API này được viết bằng Java. Ở tầng sâu hơn các API này là các thư viện được viết bằng C/C++.
3. **Hardware abstraction layer (HAL)**: Các interface chuẩn đại diện cho các thiết bị phần cứng.
4. **Linux kernel**: Nhân Linux làm lõi.

# Phát triển ứng dụng Android

### Giới thiệu

**Android Software Developer Kit (SDK)**: Là bộ công cụ phát triển ứng dụng Android, gồm có:
- Debugger, monitors, editors.
- Libraries.
- Emulators (trình giả lập thiết bị di động).
- Tài liệu nghiên cứu (developers.android.com).
- Code mẫu.

**Android Studio**: Là một IDE chính thức dành cho phát triển ứng dụng Android.

Xem hướng dẫn tải và lập trình ứng dụng Android Studio đầu tiên tại đây: [Setup Android Studio](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-2).
