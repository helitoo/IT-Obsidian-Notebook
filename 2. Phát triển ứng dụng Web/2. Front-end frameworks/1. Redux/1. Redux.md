# Giới thiệu

**Redux** là một thư viện JS cung cấp các tính năng liên quan đến *quản lý trạng thái toàn cục (global state)* rất mạnh mẽ và gọn nhẹ. Nó thường được sử dụng chung với [[1. Giới thiệu & Cài đặt ReactJS|React]]. Trong bài viết này sẽ hướng dẫn sử dụng Redux với React.

**State** (trạng thái) là toàn bộ dữ liệu đang kiểm soát logic và giao diện của trang web tại một thời điểm. Nó đóng vai trò như "bộ nhớ tạm" quyết định xem người dùng đang thấy gì và ứng dụng sẽ phản ứng ra sao khi có tương tác.

**Global state**: Là những state toàn cục, có phạm vi ảnh hưởng trên toàn bộ các trang của website.

>[!tip]
>State là những biến có thể được thay đổi giá trị để tương tác với người dùng thông qua UI.

Cài đặt:
```sh
npm install redux react-redux
```

# Nguyên lý hoạt động

![](https://images.viblo.asia/3eca7a19-82be-4c9f-8bfc-cbeac838106b.png)

- **Action**: Là hàm tác động lên state. Mỗi action được gọi bằng **Dispatcher**.
- **Store**: Là object chứa toàn bộ global state. Mỗi state sẽ được quản lý bởi 1 reducer.
- **Reducer**: Có chức năng quản lý các state thông qua các action, nó trả về state sau state đó bị tác động bởi các action.

**VD: Workflow tổng quát:**

1 - Định nghĩa tên gọi các action: Có 2 action là `INCREMENT` và `DECREMENT`.
```js
const increment = () => {
  return {
    type: "INCREMENT",
  };
};
const decrement = () => {
  return {
    type: "DECREMENT",
  };
};

```

2 - Định nghĩa reducer (`counter`), bên trong nó sẽ chứa logic cần handle cho mỗi action:
```js
// Ban đầu, state = 0
const counter = (state = 0, action) => {
  switch (action.type) {
    case "INCREMENT":
      return state + 1;
    case "DECREMENT":
      return state - 1;
  }
};

```

>[!tip]
>Các thuộc tính của action là do người dùng tự định nghĩa. Reducer chỉ việc nhận diện các thuộc tính và handle tương ứng.

3 - Đưa reducer vào store.
```js
import { createStore } from "redux";
let store = createStore(counter);
```

4 - Gọi action thông qua dispatcher:
```js
store.dispatch(increment());
store.dispatch(decrement());
// ...
```

4.1 - Lấy giá trị của state (có thể thông qua `dispatch` cũng được):

```js
store.getState()
```

**VD: Action có nhiều thuộc tính:**

```js
export const increment = (number) => {
  return {
    type: "INCREMENT",
    payload: number,
  };
};
```

```js
export const counterReducer = (state = 0, action) => {
  switch (action.type) {
    case "INCREMENT":
      return state + action.payload;
    default:
      return state;
  }
};
```

**VD: Gộp nhiều reducer vào store và tiêm vào `App`**:

```js
import { combineReducers } from "redux";

const allReducers = combineReducers({
  counter,
  // add more reducers here
});
```

`App.jsx`
```jsx
import React from "react";
import ReactDOM from "react-dom";
import { createStore } from "redux";
import { Provider } from "react-redux";

import App from "./App";
import allReducers from "./reducers";

const store = createStore(allReducers);

ReactDOM.render(
  <Provider store={store}>
    <App />
  </Provider>,
  document.getElementById("root")
);
```

Nếu store có nhiều state thì dùng toán tử `.` để lấy state ra (giống thuộc tính).
```js
const rootReducer = combineReducers({
	counter: counterReducer,
	theme: themeReducer,
});

// ...

store.getState().counter
store.getState().theme
// ...
```
