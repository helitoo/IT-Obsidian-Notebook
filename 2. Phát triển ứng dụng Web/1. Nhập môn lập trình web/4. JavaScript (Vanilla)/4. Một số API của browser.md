Browser APIs là các API được tích hợp sẵn trong trình duyệt. Chúng không thuộc ngôn ngữ JS, nhưng JavaScript có thể sử dụng chúng để tương tác với trang web, người dùng và hệ điều hành.

# DOM API

**DOM** (Document Object Model) là một cấu trúc dữ liệu cây đại diện cho nội dung tài liệu HTML hoặc XML.

Khi browser tải ra một trang web, nó sẽ:
- Phân tích cú pháp HTML để xây dựng DOM.
- Phân tích cú pháp CSS để xây dựng CSSOM.
- Xây dựng trang hoàn chỉnh bằng cách kết hợp DOM tree và CSSOM tree.

Mỗi HTML DOM có 3 thành phần:
- **Element**: Là các thẻ HTML, được sử dụng để xây dựng cấu trúc web.
- **Attribute**: cung cấp bổ sung cho element (id, class, href,…).
- **Text**: Nội dung văn bản của phần tử.

Trong đó, `window.document`, có thể viết tắt là `document` là một element đặc biệt đại diện cho toàn bộ trang HTML.

### Truy cập thành phần của DOM

Kết quả trả về của các method này gồm có 3 loại sau:

| Kiểu               | Ý nghĩa                    | Có phải danh sách? | Truy cập bằng index? | Có thuộc tính `length`? |
| ------------------ | -------------------------- | ------------------ | -------------------- | ----------------------- |
| **Element**        | Một phần tử DOM duy nhất   | ❌                  | ❌                    | ❌                       |
| **NodeList**       | Danh sách các node         | ✅                  | ✅                    | ✅                       |
| **HTMLCollection** | Danh sách các phần tử HTML | ✅                  | ✅                    | ✅                       |

Ngoài ra còn có 2 phân loại nhỏ hơn dành cho `NodeList` và `HTMLCollection`:
- **Live**: Kết quả trả về sẽ được thay đổi tự động tùy theo sự thay đổi của DOM trên thực tế (tương tự tham chiếu).
- **Static**: Ngược lại với live.

Ví dụ:

| Method                                   | Kiểu trả về      | Live / Static   |
| ---------------------------------------- | ---------------- | --------------- |
| `document.getElementById("id")`          | `Element`        | Không phân loại |
| `document.querySelector("slt")`          | `Element`        | Không phân loại |
| `document.querySelectorAll("slt")`       | `NodeList`       | **Static**      |
| `document.getElementsByTagName("tag")`   | `HTMLCollection` | **Live**        |
| `document.getElementsByClassName("cls")` | `HTMLCollection` | **Live**        |
| `element.getElementsByTagName("tag")`    | `HTMLCollection` | **Live**        |
| `element.getElementsByClassName("cls")`  | `HTMLCollection` | **Live**        |
| `element.children`                       | `HTMLCollection` | **Live**        |
| `element.childNodes`                     | `NodeList`       | **Live**        |
| `document.getElementsByName("name")`     | `NodeList`       | **Live**        |

### Thay đổi phần tử

#### Thay đổi nội dung

| Thuộc tính    | Kết quả trả về                                                        |
| ------------- | --------------------------------------------------------------------- |
| `innerHTML`   | HTML bên trong element hiện tại                                       |
| `outerHTML`   | HTML bên trong element hiện tại và HTML của chính nó                  |
| `innerText`   | Chữ đang hiển thị bên trong, nếu CSS đã ẩn element thì không lấy được |
| `outerText`   | Gần giống `innerText`                                                 |
| `textContent` | Toàn bộ chữ bên trong, bất kể CSS có ẩn hay không                     |

**VD**: In danh sách món ăn:
```js
const danhSach = document.getElementById("danhSach");
const monAn = ["Phở", "Bún chả", "Bánh mì"];

danhSach.innerHTML = monAn.map(ten => `<li>${ten}</li>`).join("");
```

#### Thay đổi style

```js
urElm.style.urStyle
```
Trả về giá CSS style của element. Trong đó, `urStyle` được viết theo kiểu *Camel case*.

#### Thay đổi attribute

```js
urElm.getAttribute("urAtt");
urElm.dataset.urAtt; // Lấy giá trị các data-* attributes
```
Lấy giá trị attribute `urAtt`.

```js
urElm.setAttribute("urAtt", "urVal");
```
Thay đổi giá trị attribute `urAtt` thành `urVal`.

Riêng đối với class, bạn còn có thể thay đổi class thông qua các phương thức của `classlist` sau:
- `urElm.classlist.add("urCls")`: Thêm class `urCls`.
- `urElm.classlist.remove("urCls")`: Xóa class `urCls`.
- `urElm.classlist.toggle("urCls")`: Thêm class `urCls` nếu `urClas` đã có, ngược lại thì xóa.
- `urElm.classlist.contains("urCls")`: Kiểm tra `urCls` có phải class của element không.

Riêng đối với id, bạn còn có thể truy xuất giá trị nhanh qua `urElm.id`.

### Chỉnh sửa cấu trúc cây DOM

```js
// Tạo mới phần tử
const urElm = document.createElement("p");

// Chỉnh sửa các thuộc tính của phần tử
urElm.textContent = "Xin chào";
urElm.classList.add("urCls");
urElm.setAttribute("urAtt", "urVal");

// Thêm phần tử vào cây DOM, trở thành con của urParent
urParent.appendChild(urElm);
```

Lưu ý:
- Nếu `urElm` đã nằm sẵn trong DOM, `appendChild` sẽ **di chuyển** nó sang vị trí mới (không tạo bản sao).
- `appendChild` trả về chính element vừa được thêm vào.
- Muốn chèn vào vị trí khác, bạn còn có thể dùng:
    - `urParent.insertBefore(urElm, urRef)`: Chèn `urElm` vào trước element con `urRef`.
    - `urParent.append(urElm, "text")`: Thêm vào cuối, cho phép thêm nhiều element hoặc chuỗi cùng lúc.
    - `urParent.prepend(urElm)`: Thêm vào đầu danh sách con.

```js
urElm.remove();
```
Xóa element khỏi cây DOM.

```js
urParent.removeChild(urElm);
```
Xóa con trực tiếp `urElm` của `urParent`. Hàm trả về element vừa bị xóa.

# Event API

**Sự kiện** (Event) là những hành vi tác động lên element.

| Sự kiện      | Sự kiện của                                                       | Kích hoạt khi                                                                                         |
| ------------ | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `mousedown`  | Elements                                                          | **Nhấn xuống** một nút chuột trên phần tử                                                             |
| `mouseup`    | Elements                                                          | **Nhả** nút chuột ra trên phần tử                                                                     |
| `click`      | Elements                                                          | Nhấn **và** nhả trên cùng một phần tử                                                                 |
| `dblclick`   | Elements                                                          | Click 2 lần liên tiếp                                                                                 |
| `mousemove`  | Elements                                                          | Con trỏ **di chuyển** trong phần tử (bắn liên tục)                                                    |
| `mouseover`  | Elements                                                          | Con trỏ **đi vào** phần tử _hoặc phần tử con của nó_                                                  |
| `mouseout`   | Elements                                                          | Con trỏ **rời khỏi** phần tử _hoặc đi vào phần tử con_                                                |
| `mouseenter` | Elements                                                          | Con trỏ đi vào chính phần tử (không tính con)                                                         |
| `mouseleave` | Elements                                                          | Con trỏ rời khỏi chính phần tử (không tính con)                                                       |
| `wheel`      | Elements                                                          | Cuộn con lăn chuột                                                                                    |
| `submit`     | `<form>`                                                          | Nút `submit` được kích hoạt                                                                           |
| `reset`      | `<form>`                                                          | Nút `reset` được kích hoạt                                                                            |
| `select`     | `<input type="text">`, `<textarea>`                               | User bôi chọn nội dung bên trong các thẻ này                                                          |
| `load`       | `window`, `<img>`, `<script>`, `<iframe>`, `<link>`, `<body>`     | Trang hoặc tài nguyên đã **tải xong hoàn toàn**                                                       |
| `unload`     | `window`, `<body>`                                                | Trang **đang bị dỡ bỏ** (đóng tab, chuyển trang). Đã lỗi thời, nên dùng `pagehide`/`visibilitychange` |
| `keydown`    | Elements (thường là phần tử đang focus), `document`               | **Nhấn xuống** một phím; lặp lại liên tục nếu giữ phím                                                |
| `keypress`   | Elements, `document`                                              | Nhấn phím có tạo ra ký tự. **Đã lỗi thời**, nên dùng `keydown` hoặc `input`                           |
| `keyup`      | Elements, `document`                                              | **Nhả** phím ra                                                                                       |
| `resize`     | `window`                                                          | Kích thước cửa sổ trình duyệt (viewport) thay đổi                                                     |
| `scroll`     | `window`, Elements có thanh cuộn                                  | Người dùng **cuộn** nội dung (bắn liên tục)                                                           |
| `focus`      | Elements có thể focus (`<input>`, `<button>`, `<a>`, `window`...) | Phần tử **nhận focus** (Khi click chuột hoặc tab vào input)                                           |
| `blur`       | Elements có thể focus, `window`                                   | Phần tử **mất focus**                                                                                 |
| `change`     | `<input>`, `<select>`, `<textarea>`                               | Phần tử **mất focus** và giá trị trong input **thay đổi**                                             |
| `input`      | `<input>`, `<select>`, `<textarea>`, phần tử `contenteditable`    | Giá trị thay đổi **ngay lập tức** theo từng thao tác (mỗi ký tự gõ vào)                               |

Bạn có thể đăng ký theo dõi xem một element có được kích hoạt sự kiện `urEvent` bằng 2 cách:

**Cách 1**: Gắn trực tiếp handler vào thuộc tính của HTML element tương ứng:
```html
<button onclick="chaoMung()">Bấm vào</button>
```

**Cách 2**: Sử dụng phương thức `.addEventListener`:
```js
document.getElementById("btn").addEventListener("click", chaoMung);
```

Trong đó, `chaoMung` là 1 [[4. Callback và Promise#Callback function|Callback function]] sẽ được gọi khi sự kiện `click` được kích hoạt. Hàm này có một tham số là `event`. `event` có một số thuộc tính sau:
- `event.type`: Loại sự kiện.
- `event.target`: Phần tử đã bị kích hoạt sự kiện.
- `event.key`: Phím được dùng để kích hoạt sự kiện.

# Đối tượng window

**Alert**: Hộp thoại hiển thị thông điệp ngắn:
```js
window.alert("Hello World");
```

**Confirm**: Hộp thoại xác nhận thông tin:
```js
const result = window.confirm("Delete this file?"); // boolean
console.log(result);
```

**Prompt**: Hộp thoại nhập chuỗi ký tự:
```js
const name = window.prompt("Your name:"); // string
console.log(name);
```

**Open**: Mở một cửa sổ mới:
```js
const urWin = window.open("urUrl", "urName", "urFeatures");
```
- `urUrl`: Địa chỉ cần mở (để rỗng sẽ mở trang trống).
- `urName`: Tên cửa sổ hoặc giá trị target như `"_blank"`, `"_self"`.
- `urFeatures`: Chuỗi cấu hình như kích thước, vị trí, ví dụ `"width=400,height=300"`.

**Close**: Đóng cửa sổ. Thông thường chỉ đóng được các cửa sổ **do script mở bằng `window.open`**; với tab do người dùng tự mở, trình duyệt sẽ chặn.
```js
urWin.close();
window.close();
```

# Storage API

Dùng để **lưu dữ liệu trực tiếp trên trình duyệt** dưới dạng key : value, cả 2 đều có kiểu string.

### Local Storage

Dữ liệu được giữ lại kể cả khi đóng trình duyệt.

```js
// Lưu dữ liệu
localStorage.setItem("username", "Alice");

// Xóa dữ liệu
localStorage.removeItem("username");

// Lấy dữ liệu
const username = localStorage.getItem("username");
```

### Session Storage

Tương tự `localStorage`, nhưng dữ liệu sẽ bị xóa khi đóng tab.

```js
sessionStorage.setItem("score", 100);
sessionStorage.getItem("score"));
// ...
```

# Location API

Cung cấp thông tin về URL hiện tại.

```js
// URL hiện tại
console.log(location.href);

// Host name hiện tại
console.log(location.hostname);

// Điều hướng đến URL khác
location.href = "https://google.com";
```

# History API

Dùng để **đọc và thay đổi lịch sử điều hướng (browser history)** mà không cần tải lại trang (reload). Đây là nền tảng của các ứng dụng Single Page Application (SPA) như React, Vue, Angular.

**VD**: Có 1 trang web đơn giản như sau:
```html
<button id="home">Home</button>
<button id="about">About</button>
<div id="content"></div>
```

Cài đặt script quản lý URL khi click vào các button:
```js
const content = document.getElementById("content");

// Hàm hiển thị nội dung của content
function render(path) {
    if (path === "/") {
        content.textContent = "Trang Home";
    } else if (path === "/about") {
        content.textContent = "Trang About";
    }
}

// Click vào #home -> Đổi URL về /, lưu trạng thái trước đó vào history
document.getElementById("home").onclick = () => {
    history.pushState({}, "", "/");
    render("/");
};

// Click vào #about -> Đổi URL về /about, lưu trạng thái trước đó vào history
document.getElementById("about").onclick = () => {
    history.pushState({}, "", "/about");
    render("/about");
};

// Quản lý sự kiện quay về URL trước đó (undo) hoặc redo
window.addEventListener("popstate", (event) => {
    console.log("URL hiện tại:", location.pathname);
    console.log("State:", event.state);
});

render(location.pathname);
```
