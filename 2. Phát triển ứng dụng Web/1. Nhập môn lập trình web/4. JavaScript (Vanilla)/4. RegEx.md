
**Regex** (Regular expression, Biểu thức chính quy) là chuỗi mô tả một tập các chuỗi theo quy tắc cú pháp, dùng để tìm kiếm, thay thế, kiểm tra chuỗi (vd: validate form).

## Khai báo

```js
// Kiểu 1
var re1 = /pattern/flags;

// Kiểu 2
var re2 = new RegExp("pattern", "flags");
```

| Flag | Ý nghĩa                                      |
| ---- | -------------------------------------------- |
| `g`  | Tìm tất cả kết quả khớp                      |
| `i`  | Không phân biệt hoa/thường                   |
| `m`  | Chế độ nhiều dòng                            |
| `u`  | Hỗ trợ Unicode                               |
| `s`  | Làm dấu `.` khớp mọi ký tự, kể cả xuống dòng |

# Các ký tự đặc biệt của pattern

### Ký tự đại diện (Metacharacter)

| Ký hiệu | Cách viết tương đương | Ý nghĩa                                                  |
| ------- | --------------------- | -------------------------------------------------------- |
| `.`     | `[^\n\r\u2028\u2029]` | Bất kỳ ký tự nào, trừ xuống dòng (khi không có flag `s`) |
| `.`     | `[\s\S]`              | Bất kỳ ký tự nào (khi có flag `s`)                       |
| `\d`    | `[0-9]`               | Chữ số                                                   |
| `\D`    | `[^0-9]`              | Không phải chữ số                                        |
| `\w`    | `[A-Za-z0-9_]`        | Ký tự thường                                             |
| `\W`    | `[^A-Za-z0-9_]`       | Không phải ký tự thường                                  |
| `\s`    | `[ \t\n\r\f\v]`       | Khoảng trắng (space, tab, xuống dòng)                    |
| `\S`    | `[^ \t\n\r\f\v]`      | Không phải khoảng trắng                                  |
| `\n`    | --                    | Xuống dòng                                               |
| `\t`    | --                    | Tab                                                      |

### Vị trí, tập ký tự, lựa chọn

| Ký hiệu  | Ý nghĩa                     | Ví dụ                    |
| -------- | --------------------------- | ------------------------ |
| `^`      | Bắt đầu chuỗi               | `/^php/`                 |
| `$`      | Kết thúc chuỗi              | `/basic$/`               |
| `[abc]`  | Một trong các ký tự a, b, c |                          |
| `[^abc]` | Ký tự không thuộc a, b, c   |                          |
| `[a-z]`  | Ký tự trong khoảng a đến z  |                          |
| `a`\|`b` | a hoặc b                    |                          |
| `(...)`  | Nhóm                        | `/(ab)+/` → "ab", "abab" |

### Bộ định lượng (Quantifiers)

| Ký hiệu | Số lần lặp          | Ví dụ                       |
| ------- | ------------------- | --------------------------- |
| `*`     | 0 hoặc nhiều        | `/a*/`                      |
| `+`     | 1 hoặc nhiều        | `/a+/`                      |
| `?`     | 0 hoặc 1 (tùy chọn) | `/colou?r/` → color, colour |
| `{n}`   | Đúng n lần          | `/\d{3}/`                   |
| `{n,}`  | Ít nhất n lần       | `/\d{2,}/`                  |
| `{n,m}` | Từ n đến m lần      | `/a{1,3}/`                  |

### Một vài phương thức liên quan

| Phương thức            | Chức năng                     | Trả về                |
| ---------------------- | ----------------------------- | --------------------- |
| `re.test(str)`         | Kiểm tra khớp mẫu             | `true` / `false`      |
| `re.exec(str)`         | Tìm kết quả khớp              | Mảng kết quả / `null` |
| `str.match(re)`        | Lấy các phần khớp mẫu         | Mảng / `null`         |
| `str.replace(re, new)` | Thay phần khớp bằng chuỗi mới | Chuỗi mới             |
| `str.search(re)`       | Tìm vị trí khớp đầu tiên      | Chỉ số / `-1`         |
| `str.split(re)`        | Tách chuỗi theo mẫu           | Mảng                  |

**VD**: Split:
```js
// 1. Tách theo khoảng trắng (một hoặc nhiều)
"a   b \t c".split(/\s+/);
// ["a", "b", "c"]

// 2. Tách theo nhiều loại dấu phân cách
"táo, cam; chuối|nho".split(/[,;|]\s*/);
// ["táo", "cam", "chuối", "nho"]

// 3. Tách theo dấu phân cách bất kỳ (không phải chữ/số)
"2024-10/25.08".split(/\D/);
// ["2024", "10", "25", "08"]

// 4. Tách theo xuống dòng (Windows hoặc Linux)
"dòng 1\r\ndòng 2\ndòng 3".split(/\r?\n/);
// ["dòng 1", "dòng 2", "dòng 3"]

// 5. Giới hạn số phần tử
"a,b,c,d".split(/,/, 2);
// ["a", "b"]

// 6. Tách thành từng ký tự
"abc".split("");
// ["a", "b", "c"]
```

**VD**: Một vài pattern kinh điển:

| Mục đích                                 | Pattern                                                               | Ví dụ khớp                   |
| ---------------------------------------- | --------------------------------------------------------------------- | ---------------------------- |
| Số nguyên                                | `/^-?\d+$/`                                                           | `42`, `-7`                   |
| Số thực                                  | `/^-?\d+(\.\d+)?$/`                                                   | `3.14`, `-0.5`               |
| Chỉ chữ cái (không dấu)                  | `/^[A-Za-z]+$/`                                                       | `Hello`                      |
| Chữ và số                                | `/^[A-Za-z0-9]+$/`                                                    | `abc123`                     |
| Họ tên tiếng Việt (có dấu)               | `/^[\p{L}\s]+$/u`                                                     | `Nguyễn Văn A`               |
| Chuỗi không rỗng/không toàn khoảng trắng | `/\S/`                                                                |                              |
| Email                                    | `/^[\w.+-]+@[\w-]+(\.[\w-]+)+$/`                                      |                              |
| Username (4-16 ký tự, chữ/số/`_`)        | `/^\w{4,16}$/`                                                        |                              |
| Mật khẩu mạnh (≥8, có hoa, thường, số)   | `/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/`                             |                              |
| Mật khẩu mạnh + ký tự đặc biệt           | `/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[^\w\s]).{8,}$/`                |                              |
| SĐT Việt Nam                             | `/^(0\|\+84)\d{9}$/`                                                  | `0912345678`, `+84912345678` |
| SĐT VN (đầu số chuẩn)                    | `/^(0\|\+84)(3\|5\|7\|8\|9)\d{8}$/`                                   |                              |
| Ngày dd/mm/yyyy                          | `/^(0[1-9]\|[12]\d\|3[01])\/(0[1-9]\|1[0-2])\/\d{4}$/`                | `25/10/2026`                 |
| Ngày yyyy-mm-dd                          | `/^\d{4}-(0[1-9]\|1[0-2])-(0[1-9]\|[12]\d\|3[01])$/`                  | `2026-10-25`                 |
| Giờ hh:mm (24h)                          | `/^([01]\d\|2[0-3]):[0-5]\d$/`                                        | `23:59`                      |
| Mã bưu điện / OTP 6 số                   | `/^\d{6}$/`                                                           | `123456`                     |
| URL                                      | `/^https?:\/\/[\w.-]+(\.[\w.-]+)+(\/\S*)?$/`                          |                              |
| Địa chỉ IPv4                             | `/^((25[0-5]\|2[0-4]\d\|1?\d?\d)\.){3}(25[0-5]\|2[0-4]\d\|1?\d?\d)$/` |                              |
| Mã màu hex                               | `/^#([0-9a-fA-F]{3}\|[0-9a-fA-F]{6})$/`                               |                              |
| Thẻ HTML                                 | `/<\/?[\w\s="'-]+>/g`                                                 |                              |
