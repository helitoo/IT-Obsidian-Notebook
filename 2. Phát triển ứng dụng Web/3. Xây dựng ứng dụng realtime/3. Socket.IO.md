# Giới thiệu và hướng dẫn cài đặt

Socket.IO là một thư viện giúp xây dựng ứng dụng realtime giữa client và server.

>[!important]
>- Socket.IO được xây dựng chủ yếu cho hệ sinh thái Node.js và sử dụng một protocol cao hơn WebSocket thuần. Vì vậy, khi backend chính không phải Node.js, việc tích hợp Socket.IO thường kém tự nhiên và làm tăng coupling với Node.js.
>- Trong trường hợp đó, nên ưu tiên cơ chế realtime native của backend/framework hoặc WebSocket chuẩn. Nếu vẫn muốn dùng Socket.IO, có thể triển khai một Node.js Socket.IO server riêng như một realtime service. Server riêng này không nhất thiết là microservice.

# Nguyên lý hoạt động cơ bản

### Khai báo Socket.IO

Để triển khai Socket.IO, cần khai báo sử dụng nó ở cả client và server.
- Tại server, sử dụng [**`socket.io`**](https://www.npmjs.com/package/socket.io).
- Tại client, sử dụng [**`socket.io-client`**](https://www.npmjs.com/package/socket.io-client).

Trên thực tế, `socket.io-client` đã được cài sẵn vào `socket.io` và bạn có thể triển khai nó như sau:

`server.js`
```js
import express from 'express';
import { createServer } from 'node:http';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import { Server } from 'socket.io';

const app = express();
const server = createServer(app);
const io = new Server(server);

const __dirname = dirname(fileURLToPath(import.meta.url));

app.get('/', (req, res) => {
  res.sendFile(join(__dirname, 'index.html'));
});

io.on('connection', (socket) => {
  console.log('A user connected');
});

server.listen(3000, () => {
  console.log('The server running at http://localhost:3000');
});
```

`client.html`
```html
<script src="/socket.io/socket.io.js"></script>
<!-- <script src="https://cdn.socket.io/4.8.3/socket.io.min.js"></script> -->
<script>
  var socket = io();
</script>
```

Khi khởi chạy server:
```sh
node server.js
```
Bạn sẽ thấy thông báo `A user connected`.

### Quản lý sự kiện và kênh

Xem thêm về cách quản lý sự kiện [tại đây](https://socket.io/docs/v4/tutorial/api-overview).

#### Đặt tên kênh, emit và on

Socket.IO cho phép **tùy ý** đặt tên cho kênh và **tùy ý** trong dạng dữ liệu trao đổi.

Có 2 phương thức để quản lý sự kiện:
- **`socket.emit()`**: Gửi dữ liệu.
- **`socket.on()`**: Nhận dữ liệu.

Trong đó, tham số đầu tiên là tên kênh, do lập trình viên quy định. Mỗi kênh gồm 2 sự kiện là nhận và gửi (theo 1 chiều).

`client.html`
```html
<script src="/socket.io/socket.io.js"></script>
<script>
  var socket = io();

  var form = document.getElementById('form');
  var input = document.getElementById('input');

  form.addEventListener('submit', function(e) {
    e.preventDefault();
    if (input.value) {
      // Gửi input.value vào sự kiện "chat message"
      socket.emit('chat message', input.value);
      input.value = '';
    }
  });
</script>
```

`server.js`
```js
io.on('connection', (socket) => {
  // Nhận msg từ sự kiện "chat message"
  socket.on('chat message', (msg) => {
    console.log('message: ' + msg);
  });
});
```

#### Emit trên broadcast

Có 2 cách để gửi message vào broadcast.

**Cách 1**: Sử dụng phương thức `io.emit` (toàn cục):
`server.js`
```js
io.emit('hello', 'world'); 
```

**Cách 2**: Sử dụng phương thức `socket.broadcast.emit` khi lắng nghe sự kiện:
`server.js`
```js
io.on('connection', (socket) => {
  socket.on('chat message', (msg) => {
    io.emit('chat message', msg);
  });
});
```

**Lắng nghe kênh ở broadcast**: Dùng `socket.on` như bình thường.
`client.html`
```html
<script src="/socket.io/socket.io.js"></script>
<script>
  var socket = io();

  // ...

  // emit event

  // on event
  socket.on('chat message', function(msg) {
    // ...
  });
</script>
```

#### Room

Room là một kênh mà người dùng có thể vào hoặc ra. Socket.IO hỗ trợ các phương thức là:
- `socket.join('roomName')`: Vào room.
- `socket.leave('roomName')`: Rời room.
- `socket.to('roomName').emit('channelName', data)`: Gửi dữ liệu đến mọi user trong room.
- `socket.except('roomName').emit('channelName', data)`: Gửi dữ liệu đến broadcast ngoại trừ những người trong room này.

```js
io.on('connection', (socket) => {
  // join the room named 'some room'
  socket.join('some room');
  
  // broadcast to all connected clients in the room
  io.to('some room').emit('hello', 'world');

  // broadcast to all connected clients except those in the room
  io.except('some room').emit('hello', 'world');

  // leave the room
  socket.leave('some room');
});
```

#### Khôi phục trạng thái connection (Connection State Recovery - CSR)

CSR là một tính năng mạnh trong Socket.IO, cho phép khôi phục lại một số sự kiện gần nhất nếu chẳng may nó bị mất kết nối, bao gồm các việc khôi phục lại các message hoặc các room bị mất.

>[!important] Phân biệt Reconnection và SSR
>- **Reconnection**: Cố gắng tạo kết nối mới khi kết nối cũ chết. Hành vi này đã được tự động hóa trong Socket.IO.
>- **CSR**: Cố gắng khôi phục lại các sự kiện khi connection chết với ID đã có, không phải tạo mới connection.

Để bật tính năng này, chỉ cần thêm thuộc tính `connectionStateRecovery` vào `io`:
```js
const io = new Server(server, {
  connectionStateRecovery: {}
});
```

Nguyên lý của CSR là nó sẽ lưu lại các sự kiện trong một khoảng thời gian ngắn gần nhất, khi cần chỉ cần đem ra sử dụng thôi.

>[!important]
>- Do bộ nhớ của server là có hạn, CSR cũng là có hạn.
>- CSR chỉ cố gắng khôi phục, không phải luôn luôn khôi phục thành công. Sự thành công của nó còn phụ thuộc vào server.
