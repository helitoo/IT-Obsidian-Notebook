
# Khai báo và khởi tạo lớp và đối tượng

**Khai báo lớp**:
```php
class className {
	// attributes ...
	// methods ...
}
```

**Khai báo đối tượng**:
```php
$objectName = new className;
$objectName->memberName; // Truy xuất đến các thành phần của lớp
```

**VD**:
```php
class Animal {
    public $name; 
    protected $age;
    private $secret;
    
    public function __construct($name, $age, $secret) {
        $this->name = $name;
        $this->age = $age;
        $this->secret = $secret;
    }
    
    protected function showAge() {
        echo $this->age;
    }
    
    private function showSecret() {
        echo $this->secret;
    }
}
```

# Các thành phần của lớp

### Phạm vi truy cập

Giống C++:

| Modifier    | Phạm vi truy cập                                                        |
| ----------- | ----------------------------------------------------------------------- |
| `public`    | Truy cập được từ **mọi nơi**.                                           |
| `protected` | Truy cập được từ **bên trong class đó** và các **class con (kế thừa)**. |
| `private`   | Chỉ truy cập được từ **bên trong chính class đó**.                      |

### Phương thức khởi tạo

Là phương thức có tên là `__construct` hoặc `className` và có phạm vi `public`.

**VD**:
```php
public function __construct($name, $age, $color);
public function __construct();

public function className($name, $age, $color);
public function className();
```

Để trỏ đến đối tượng hiện tại, PHP dùng từ khóa `this` giống C++.

### Phương thức hủy

Là phương thức có tên là `__destruct`.

# Các đặc tính của OOP

### Tính kế thừa

Dùng từ khóa `extends` để chỉ một lớp là kế thừa một lớp khác toàn bộ thuộc tính và phương thức (trừ `private`).

>[!important]
>Mỗi lớp chỉ có thể được kế thừa (`extends`) 1 lần, ngoại trừ nếu lớp cha là `interface` hoặc `final` (ngăn chặn kế thừa).

```php
class baseClass {
	// ...
}

class subClass extends baseClass {
	// ...
}
```

**VD**:
```php
class Animal {
    public $name;
    
    public function __construct($name) {
        $this->name = $name;
    }
    
    public function eat() {
        echo $this->name . " đang ăn.<br>";
    }
}

class Dog extends Animal {
    public function bark() {
        echo $this->name . " đang sủa.<br>";
    }
}

$d = new Dog("Milu");
$d->eat();    // "Milu đang ăn." - gọi method kế thừa từ Animal
$d->bark();   // "Milu đang sủa." - gọi method riêng của Dog
```

Lớp con có thể chủ động gọi thành phần của lớp cha (có tên giống với thành phần của lớp con) bằng tiền tố **`parent::`**:
```php
class Animal {
    protected $name;
    
    public function __construct($name) {
        $this->name = $name;
    }
    
    public function eat() {
        echo $this->name . " đang ăn.<br>";
    }
}

class Dog extends Animal {
    private $breed;
    
    public function __construct($name, $breed) {
	    // Dùng constructor của cha để khởi tạo name trước
        parent::__construct($name);
        // Tự khởi tạo breed
        $this->breed = $breed;
    }
    
    public function eat() {
        parent::eat();
        echo $this->breed . " ăn khá nhiều.<br>";
    }
}

$d = new Dog("Milu", "Poodle"); // Milu đang ăn.
$d->eat(); // Poodle ăn khá nhiều.
```

### Lớp `abstract`

Lớp trừu tượng là lớp **không thể khởi tạo đối tượng trực tiếp** (`new`), chỉ dùng để làm "khuôn mẫu" cho các class con kế thừa. Có thể chứa cả phương thức đã hiện thực (bình thường) lẫn phương thức **trừu tượng** (chỉ khai báo, chưa có nội dung, bắt buộc class con phải hiện thực lại).

Mỗi lớp chỉ có thể

**VD**:
```php
abstract class Shape {
    protected $name;
    
    public function __construct($name) {
        $this->name = $name;
    }
    
    // Phương thức bình thường - dùng chung cho mọi class con
    public function display() {
        echo $this->name . " có diện tích: " . $this->area() . "<br>";
    }
    
    // Phương thức trừu tượng - KHÔNG có phần thân {}
    // Bắt buộc class con phải tự triển khai
    abstract public function area();
}

class Circle extends Shape {
    private $radius;
    
    public function __construct($radius) {
        parent::__construct("Hình tròn");
        $this->radius = $radius;
    }

    public function area() {
        return round(3.14 * $this->radius * $this->radius, 2);
    }
}

// $s = new Shape("Test"); // Lỗi - không thể khởi tạo abstract class
$c = new Circle(5);
$c->display(); // "Hình tròn có diện tích: 78.5"
```

### Lớp `interface`

Là lớp trừu tượng mà mọi thành phần đều trừu tượng và phải `public`.

**VD**:
```php
interface Payable {
    public function calculateSalary();
}

class Employee implements Payable {
    private $baseSalary;
    
    public function __construct($baseSalary) {
        $this->baseSalary = $baseSalary;
    }
    
    public function calculateSalary() {
        return $this->baseSalary;
    }
}

$e = new Employee(1000);
echo $e->calculateSalary(); // 1000
```
