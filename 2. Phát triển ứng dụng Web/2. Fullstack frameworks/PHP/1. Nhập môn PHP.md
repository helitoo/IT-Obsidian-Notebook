
**PHP** (*PHP Hypertext Preprocessor*, `.php`) là ngôn ngữ lập trình web phía server (*server-side scripting*). Mỗi một webpage thực chất là 1 file `.php`. Khi user thao tác với trang, server phải load lại toàn bộ.

**Composer** là trình quản lý thư viện (dependency manager) của PHP. Tải composer [tại đây](https://getcomposer.org/download/).

# Cài đặt

Thường sẽ sử dụng [XAMPP](https://www.apachefriends.org/) (*Windows*) và [MAMP](https://www.mamp.info/) (*iOS*).

Đây là các bộ công cụ giúp bạn tạo môi trường web server local trên máy tính, để chạy website/app web mà không cần đưa lên Internet.

>[!note]
>Thay vì phải cài Apache + PHP + MySQL + cấu hình từng thứ riêng lẻ, bạn cài Laragon/XAMPP/MAMP → có gần như toàn bộ môi trường để lập trình web ngay.

>[!tip]
>Mặc định, để dùng PHP bạn phải thông qua các tool trên. Đối với XAMPP, bạn có thể sử dụng PHP ở toàn cục bằng cách thêm `C:\xampp\php` (*và các tool khác nếu cần*) vào Environment Variables Path.

Lệnh kiểm tra:
```sh
php -v
composer --version
```

### Xuất dữ liệu

Có 3 cách:

| Đặc điểm              | `echo`                                            | `print`                  | `var_dump`                           |
| --------------------- | ------------------------------------------------- | ------------------------ | ------------------------------------ |
| Là gì                 | Ngôn ngữ construct                                | Ngôn ngữ construct       | Hàm (function)                       |
| Giá trị trả về        | Không có                                          | Trả về `1`               | Không có                             |
| Số tham số            | Nhận nhiều giá trị, ngăn cách bởi dấu `,`         | Chỉ nhận 1 giá trị       | Nhận nhiều giá trị                   |
| Hiển thị kiểu dữ liệu | Không                                             | Không                    | **Có** (type + length/size)          |
| Tốc độ                | Nhanh hơn (nhỉnh hơn không đáng kể)               | Chậm hơn `echo` một chút | Chậm nhất vì phải phân tích cấu trúc |
| Dùng dấu ngoặc        | Không bắt buộc: `echo "abc";` hoặc `echo("abc");` | Không bắt buộc           | Bắt buộc: `var_dump($x);`            |

**VD**:
```php
$name = "Bảo";
$age = 22;

// echo
echo "Tên: ", $name, ", tuổi: ", $age; // Tên: Bảo, tuổi: 22

// print
$result = print "Xin chào"; // Xin chào

// var_dump
var_dump($name); // string(4) "Bảo"
var_dump($age); // int(22)

$arr = ["a" => 1, "b" => 2];
var_dump($arr); // array(2) { ["a"]=> int(1) ["b"]=> int(2) }
```

### Kiểu dữ liệu

Một biến trong PHP có thể lưu được bất kỳ kiểu dữ liệu nào và không cần khai báo kiểu dữ liệu khi khai báo biến.

#### Kiểu dữ liệu và các phương thức kiểm tra

| Kiểu            | Hàm kiểm tra    |
| --------------- | --------------- |
| `bool`          | `is_bool(v)`    |
| `int`           | `is_integer(v)` |
| `float`, `real` | `is_double(v)`  |
| `string`        | `is_string(v)`  |
| `array`         | `is_array(v)`   |
| `object`        | `is_object(v)`  |

**Kiểm tra kiểu**:
```php
is_bool(true);              // true
is_bool("true");            // false

is_integer(10);             // true
is_integer(10.5);           // false
is_integer("10");           // false

is_double(10.5);            // true
is_double(10);              // false
is_double("10.5");          // false

is_string("Hello");         // true
is_string(123);             // false

is_array([1, 2, 3]);        // true
is_array("Hello");          // false

is_object(new stdClass());  // true
is_object([1, 2]);          // false - mảng không phải object
```

**Lấy kiểu**:
```php
gettype(10);                // "integer"
gettype(10.5);               // "double"
gettype("Hello");            // "string"
gettype(true);                // "boolean"
gettype([1, 2, 3]);          // "array"
gettype(new stdClass());     // "object"
gettype(null);                // "NULL"
```

**`isset(v)` - Kiểm tra sự tồn tại của biến**: Một biến tồn tại khi nó được khai báo và có giá trị khác `null`.
```php
$a = "Hello";
$b = null;
isset($a);                   // true - biến tồn tại và khác null
isset($b);                   // false - dù đã khai báo nhưng giá trị là null
isset($c);                   // false - biến chưa khai báo
```

**`unset(v)` - Hủy biến**: Là giải phóng bộ nhớ biến, làm cho biến đó như chưa từng tồn tại.
```php
$a = "Hello";
unset($a);
isset($a);                   // false - biến đã bị hủy
```

**`empty(v)` - Kiểm tra tính falsy và tính tồn tại của biến**:
```php
empty("");                   // true - chuỗi rỗng
empty("0");                  // true - chuỗi "0" cũng được coi là rỗng
empty(0);                    // true
empty(null);                 // true
empty([]);                   // true - mảng rỗng
empty("Hello");               // false
empty($undefinedVar);        // true - biến chưa khai báo cũng coi là rỗng
```

#### Mảng

Mảng trong PHP có thể tương đương với map trong các ngôn ngữ khác, với key mặc định là 0-based.

**Khai báo**:
```php
# Mảng 1 chiều
$a = array();

# Mảng 2 chiều
$a=array();
for($i = 0; $i < 2; $i ++)
	$a[$i]=array();
```

**Khai báo và khởi tạo**:
```php
$words = array("a", "b", "c");
```

**Truy xuất phần tử**:
```php
$echo $words[0];
```

**Gắn key cho mảng**:
```php
$numbers = array("first" => 1, "second" => 2, 3);
echo $numbers["first"];
```

**Duyệt mảng**:
```php
# Duyệt mảng không có key
for ($i = 0; $i < count($A); $i++)
	echo $a[$i] . "<br>";

# Duyệt mảng có key
$age = array("Tú"=>"35", "Tùng"=>"37", "Tâm"=>"43");
foreach($age as $key => $value) {
	echo "Key=" . $key . ", Value=" . $value;
	echo "<br>";
}
```

**Thêm phần tử vào mảng**:
```php
$fruits = ["táo", "cam"];

// Thêm element(s) vào cuối mảng
array_push($fruits, "xoài", "nho");
// ["táo", "cam", "chuối", "xoài", "nho"]

// Thêm element(s) vào đầu mảng
array_unshift($fruits, "xoài", "nho");
```

**Xóa phần tử khỏi mảng**:
```php
// array_pop(array) - Lấy phần tử cuối ra khỏi mảng
$fruits = ["táo", "cam", "chuối"];
$last = array_pop($fruits);
echo $last;          // "chuối"
print_r($fruits);    // ["táo", "cam"] - mảng gốc đã bị thay đổi

// array_shift(array) - Lấy phần tử đầu ra khỏi mảng
$fruits = ["táo", "cam", "chuối"];
$first = array_shift($fruits);
echo $first;          // "táo"
print_r($fruits);     // ["cam", "chuối"] - các key được đánh số lại từ 0
```

**Kết hợp mảng**:
```php
// Kết 2 mảng lại và trả ra mảng mới
$a = ["táo", "cam"];
$b = ["chuối", "xoài"];
$merged = array_merge($a, $b);
print_r($merged);
// ["táo", "cam", "chuối", "xoài"]

// Với mảng có key trùng, giá trị sau sẽ ghi đè giá trị trước
$a = ["a" => 1, "b" => 2];
$b = ["b" => 20, "c" => 3];
$merged = array_merge($a, $b);
print_r($merged);
// ["a" => 1, "b" => 20, "c" => 3]
```

**Sắp xếp mảng**:
```php
// sort(array, flag) - Sắp xếp mảng tăng dần, đánh lại key từ 0
$numbers = [5, 2, 8, 1, 9];
sort($numbers); // [1, 2, 5, 8, 9]

$numbers = ["10", "9", "2", "1"];
sort($numbers, SORT_STRING); // ["1", "10", "2", "9"] - Ép về chuỗi

sort($numbers, SORT_NUMERIC); // [1, 2, 9, 10] - Ép về số
```

| Tăng dần  | Giảm dần   | Đối tượng được dùng để so sánh | Bảo toàn key sau khi sort?             |
| --------- | ---------- | ------------------------------ | -------------------------------------- |
| `sort()`  | `rsort()`  | Value.                         | **Không** - key bị đánh số lại từ `0`. |
| `asort()` | `arsort()` | Value.                         | **Có** - giữ nguyên key gốc.           |
| `ksort()` | `krsort()` | Key.                           | **Có** - giữ nguyên key gốc.           |

>[!tip]
>Chỉ có **`sort()` và `rsort()`** là phá key (đánh số lại từ 0), vì bản chất của nó coi mảng như một **danh sách (list)** thuần túy, không quan tâm key cũ là gì. Còn lại tất cả các hàm có tiền tố `a` (theo value, giữ key) hoặc `k` (theo key) đều **giữ nguyên cặp key-value**, chỉ thay đổi thứ tự sắp xếp.

**`usort()` - Hàm sắp xếp tự định nghĩa**: Sử dụng hàm `usort()` và toán tử `<=>`, `A <=> B` có 3 kết quả:
- `-1` nếu A < B.
- `0` nếu A = B.
- `1` nếu A > B.
```php
$students = [
    ["name" => "Tú", "score" => 8.5],
    ["name" => "Tùng", "score" => 9.2],
    ["name" => "Tâm", "score" => 7.0],
];

// Sắp xếp theo điểm giảm dần
usort($students, function ($a, $b) {
    return $b["score"] <=> $a["score"];   // đổi chỗ $a, $b để giảm dần
});

foreach ($students as $s) {
    echo $s["name"] . ": " . $s["score"] . "\n";
}
// Tùng: 9.2 / Tú: 8.5 / Tâm: 7.0
```

#### Ép kiểu

**Ép kiểu tường minh**:
- `(dataType) $varName`.
- `settype($var, "dataType")`.

**Ép kiểu ngầm định**:
- Đối với biểu thức có toán tử số học, PHP cố gắng ép kiểu về số học.
- Đối với biểu thức có toán tử nối chuỗi, PHP cố gắng ép kiểu về `string`.

|                                             | `null` | `true` | `false` |
| ------------------------------------------- | ------ | ------ | ------- |
| **Toán tử số học**<br>(`+` `-` `*` `/` `%`) | `1`    | `1`    | `0`     |
| **Toán tử nối chuỗi**<br>(`.`)              | `""`   | `"1"`  | `""`    |

| False       | Truehy                         |
| ----------- | ------------------------------ |
| `false`     | `true`                         |
| `0`, `0.0`  | Số khác `0`, `0.0`.            |
| `""`, `"0"` | Chuỗi khác rỗng và khác `"0"`. |
| `[]`        | Mảng khác rỗng.                |
| `null`      | Object.                        |

>[!tip]
>Để tránh các lỗi ngoài mong đợi do ép kiểu ngầm định, nên dùng:
>- Strict comparison (`===`, `!==`) để so sánh.
>- Chủ động ép kiểu.

#### Toán tử

| Loại     | Toán tử                                                |
| -------- | ------------------------------------------------------ |
| Toán học | `+`, `-`, `*`, `**` (*lũy thừa*), `/`, `%`, `++`, `--` |
| Gán      | `=`, `+=`, `-=`, `*=`, `/=`, `%=`                      |
| So sánh  | `>`, `<`, `<=`, `>=`, `==`, `!=`, `===`, `!==`         |
| Logic    | `&&`, `\|\|`                                           |

**Toán tử 3 ngôi**:
```php
// Dạng đầy đủ
$result = (condition) ? val_if_true : val_if_false;

// Dạng rút gọn
$result = v1 ?: v2; // Nếu v1 là truthy thì return v1, ko thì return v2
```


### Thời gian

#### `date()` - Lấy ngày dạng chuỗi

```php
date("d/m/Y");          // 09/09/2026
date("D, d M Y H:i:s"); // Wed, 09 Sep 2026 14:30:00
```

**Các loại format ngày tháng năm**:

|Định dạng|Mô tả|Giá trị|
|---|---|---|
|`d`|Ngày trong tháng, 2 ký tự|01-31|
|`D`|Ngày trong tuần, 3 ký tự|Mon-Sun|
|`j`|Ngày trong tháng, không có số 0 đứng trước|1-31|
|`S`|Hậu tố của ngày trong tháng|st, nd, rd|
|`z`|Ngày trong năm|0-365|
|`w`|Ngày trong tuần theo số|0 (CN) - 6 (T7)|
|`W`|Tuần trong năm|1-52|
|`F`|Tháng dạng chuỗi đầy đủ|January|
|`m`|Tháng, 2 ký tự|01-12|
|`M`|Tháng, 3 ký tự|Jan-Dec|
|`n`|Tháng, không có số 0 đứng trước|1-12|
|`t`|Số ngày tối đa trong tháng|28-31|
|`L`|Năm nhuận|0, 1|
|`Y`|Năm đầy đủ|2026|
|`y`|2 ký tự cuối của năm|26|

**Các loại format giờ phút giây**:

|Định dạng|Mô tả|Giá trị|
|---|---|---|
|`a`|Buổi trong ngày, chữ thường|am-pm|
|`A`|Buổi trong ngày, chữ hoa|AM-PM|
|`g`|Định dạng 12h, không có số 0 đứng đầu|1-12|
|`G`|Định dạng 24h, không có số 0 đứng đầu|0-24|
|`h`|Định dạng 12h, có số 0 đứng đầu|01-12|
|`H`|Định dạng 24h, có số 0 đứng đầu|00-23|
|`i`|Phút|00-59|
|`s`|Giây|00-59|

>[!tip]
>- Chữ thường (`d`, `m`, `y`, `h`,...) -> Trả về giá trị **có số `0` đứng trước**.
>- Chữ hoa hoặc biến thể (`j`, `n`, `G`,...) -> **Không** có bộ đệm `0`.

#### `getdate()` - Lấy ngày dạng mảng

```php
$today = getdate();
print_r($today);
```

`getdate()` trả về một mảng có các key sau:

| Key         | Ý nghĩa                       |

| `[hours]`   | Ggiờ                          |

| `[wday]`    | Ngày trong tuần, 0 → Chủ nhật |
| `[weekday]` | Thứ trong tuần dạng chuỗi     |

#### `strtotime()`  - Chuyển kiểu dữ liệu thời gian

```php
$timestamp = strtotime("2026-09-09");
echo date("d/m/Y", $timestamp); // 09/09/2026

$timestamp2 = strtotime("+1 day"); // Ngày mai
$timestamp3 = strtotime("next monday"); // Thứ 2 tuần sau
```

>[!tip]
>`strtotime()` hiểu được cả các cụm từ ngôn ngữ tự nhiên tiếng Anh như `"+1 week"`, `"-3 months"`, `"tomorrow"`, `"last friday"`.

#### `DateInterval` - Khoảng thời gian

```php
$start = new DateTime("2026-01-15");
$end   = new DateTime("2026-09-09");

# Lấy khoảng thời gian giữa 2 thời điểm
$interval = $start->diff($end);

echo $interval->y . " năm ";
echo $interval->m . " tháng ";
echo $interval->d . " ngày";
// 0 năm 7 tháng 25 ngày
```

>[!important]
>- `DateInterval` chỉ tính được từ đối tượng `DateTime`.
>- Để tính khoảng thời gian bằng các đối tượng khác, dùng các hàm số học thông thường.

**Các thuộc tính của đối tượng `DateInterval`**:

|Thuộc tính|Ý nghĩa|
|---|---|
|`y`|Số năm chênh lệch|
|`m`|Số tháng chênh lệch|
|`d`|Số ngày chênh lệch|
|`h`|Số giờ chênh lệch|
|`i`|Số phút chênh lệch|
|`s`|Số giây chênh lệch|
|`days`|Tổng số ngày chênh lệch (tính gộp)|
|`invert`|`1` nếu `$start` lớn hơn `$end`, ngược lại `0`|

**Tính khoảng thời gian bằng các hàm số học**:
```php
$t1 = time(); // Số giây từ 1/1/1970 đến thời điểm hiện tại
$t2 = strtotime("2026-12-25"); // Số giây từ 1/1/1970 đến 25/12/2026
$m = abs($t2 - $t1);
$days = floor($m / (60 * 60 * 24));
```

### Hàm

**Khai báo và gọi hàm cơ bản**:
```php
function funcName($param1, $param2) {
    // ...
    return $result;
}

// Gọi hàm
$result = funcName(1, 2);
```

**Tham số mặc định**:
```php
function hello($ten = "bạn") {
    echo "Xin chào, $ten!\n";
}

hello();          // "Xin chào, bạn!"
hello("Bảo");     // "Xin chào, Bảo!"
```

**Tham số tham chiếu**:
```php
function increase(&$x) {
    $x++;   // thay đổi trực tiếp biến gốc
}

$num = 5;
increase($num); // num = 6
```

### Module hóa dự án PHP

Có 2 phương pháp là `include` và `require`:

| Đặc điểm               | `include`                                                                              | `require`                                         |
| ---------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Khi file không tồn tại | Ném ra **Warning**, script chạy tiếp các dòng phía sau. Dòng nào thiếu hàm sẽ báo lỗi. | Ném ra **Fatal Error**, script **dừng**.          |
| Mức độ nghiêm trọng    | Nhẹ - dùng cho file không bắt buộc.                                                    | Nghiêm ngặt - dùng cho file **bắt buộc phải có**. |

**Vấn đề đặt ra**:
- File `A` include `B` và `C`. File `B` đã include `C` sẵn rồi -> Lỗi.
- Giải pháp: Dùng **`include_once`** / **`require_once`**.

**VD**:

`functions.php`
```php
<?php
	function hello() {
	    echo "Hello!\n";
	}
	
	function sum($a, $b) {
	    return $a + $b;
	}
```

`header.php`
```php
<?php
	include "functions.php";
	echo "<header>Website của tôi</header>\n";
```

`index.php`
```php
<?php
	include "functions.php"; 
	include "header.php"; // Lỗi, vì trong header.php đã include functions rồi, khắc phục bằng cách thay bằng include_once
	
	hello();
	echo sum(3, 5);
```
