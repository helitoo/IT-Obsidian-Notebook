
Hiện nay có 2 phương pháp để kết nối PHP với MySQL là dùng thư viện **MySQLi** hoặc **PDO**. PDO thì được tích hợp sẵn vào PHP.

**Tổng quan quy trình kết nối PHP với MySQL**:
1. Kết nối với server database.
2. Chọn database.
3. Xây dựng query.
4. Thực thi query.
5. Nhận và xử lý kết quả trả về.
6. Ngắt kết nối với server database.

# MySQLi

### Quản lý kết nối với database

```php
$SERVER = "localhost";
$USERNAME = "root";
$PASSWORD = "";
$DBNAME = "qlsv";

// Kết nối
$conn = mysqli_connect($SERVER, $USERNAME, $PASSWORD, $DBNAME)
or die("Connection failed. Detail: " . mysqli_connect_error());

echo "Connected.";

// Đóng kết nối
mysqli_close($conn);
```

### Quản lý truy vấn

```php
$res = mysqli_query($conn, $sqlStatement)
or die("Query failed");
```
Trong đó, `$sqlStatement` là một chuỗi thể hiện query.

#### Prepared Statement

```php
// Chuẩn bị câu lệnh INSERT với 3 tham số ẩn danh
$sql = "INSERT INTO persons (first_name, last_name, age) VALUES (?, ?, ?)";

if ($stmt = mysqli_prepare($conn, $sql)) {
    // Liên kết biến với 3 tham số trong câu lệnh đã chuẩn bị
    mysqli_stmt_bind_param(
	    $stmt,
	    "ssi", // string string integer
	    $first_name,
	    $last_name,
	    $age
	);
	
    // Thiết lập tham số lần 1
    $first_name = "abc";
    $last_name  = "xyz";
    $age        = 20;

    // Thực hiện câu lệnh
    mysqli_stmt_execute($stmt);
    
    // Lấy kết quả để xử lý, nếu là SELECT
    // $result = mysqli_stmt_get_result($stmt);

    // Thiết lập tham số lần 2 (nếu cần)
    $first_name = "efg";
    $last_name  = "vmk";
    $age        = 25;

    // Thực hiện câu lệnh
    mysqli_stmt_execute($stmt);

    // Đóng statement
    mysqli_stmt_close($stmt);
} else {
    echo "Prepared statement failed";
```

Các kiểu dữ liệu:
- `i`: Integer.
- `d`: Double.
- `s`: String.

#### Các giá trị trả về của `mysqli_query`

- **Đối với các lệnh `CREATE`**: Không trả về gì.
- **Đối với `INSERT`, `UPDATE`, `DELETE`**: Trả về `1` (nếu thành công), `0` (nếu thất bại).
- **Đối với `SELECT`**: Trả về kết quả truy vấn.

#### Xử lý kết quả `SELECT`

```php
echo "<table>";
echo "<tr><th>Username</th><th>Password</th></tr>";
while ($row = mysqli_fetch_row($res)) {
	echo "<tr>";
	echo "<td>" . $row[0] . "</td>";
	echo "<td>" . $row[1] . "</td>";
	echo "</tr>";
}
echo "</table>";
```
