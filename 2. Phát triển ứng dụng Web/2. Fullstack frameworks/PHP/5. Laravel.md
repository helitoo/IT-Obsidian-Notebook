**Laravel** là 1 PHP full-stack framework open-source dùng để xây dựng các ứng dụng web. Phần front-end của nó là tích hợp thêm các framework khác như React, Vue,... hoặc Vanilla vào.

# Cài đặt và khởi động server

**Bước 1**: Cài đặt Laravel Installer:
```sh
composer global require laravel/installer
```

**Bước 2**: Kiểm tra đường dẫn tới Laravel bằng lệnh sau và thêm đường dẫn đó vào Environment Variables Path:
```sh
composer global config bin-dir --absolute
```

**Bước 3**: Khởi động lại terminal và khởi tạo dự án Laravel:
```sh
laravel new your-app-name
```

>[!tip]
>Khi khởi tạo dự án, Laravel Installer có thể sẽ hỏi bạn các framework front-end được tích hợp. Hãy điền `no` hoặc bỏ trống toàn bộ nếu không có nhu cầu.

Trong trường hợp bạn muốn sử dụng Laravel như một back-end (không có giao diện), hãy bật chế độ API bằng lệnh sau:
```sh
cd your-app-name
php artisan install:api
```

**Khởi chạy server**: Trường hợp dùng Laravel cho cả front-end và back-end:
```sh
cd example-app
npm install && npm run build
composer run dev
```

**Khởi chạy server**: Trường hợp dùng Laravel chỉ cho back-end:
```sh
php artisan serve
```

Mặc định, Laravel sẽ chạy ở `localhost:8000`.
