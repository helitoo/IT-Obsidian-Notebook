
HTTP/HTTPS là giao thức stateless, tức là mỗi request là độc lập, server đều không nhớ dữ liệu giữa 2 lần load khác nhau. Cho nên cần có các cơ chế để PHP nhớ dữ liệu qua mỗi lần load trang.

Có 4 phương pháp:

| Phương pháp  | So sánh với React/NodeJS                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **GET/POST** | Giống như bạn gửi query string hoặc body trong 1 request `fetch()` - nhưng ở đây browser gửi và **cả trang được load lại** thay vì chỉ nhận JSON. |
| **Cookie**   | Giống hệt cookie trong Node.js (`res.cookie()`, `document.cookie`) - vẫn dùng để lưu token, remember-login.                                       |
| **Session**  | Giống `express-session` ở backend NodeJS - server lưu data theo session ID, cũng phải dùng cookie để gửi session ID qua lại.                      |

# GET

**Đặc điểm**:
- Dữ liệu được gửi kèm theo **địa chỉ URL** dưới dạng `varName=value`.
- Các cặp `varName=value` cách nhau bởi dấu `&`.

**VD**: URL:
```
https://domain/pathfile?fieldname1=value1&fieldname2=value2
```

**VD**: Form:

`login.php`
```html
<form name="form1" method="get" action="index.php">
    <input name="USER" type="text">
    <input name="PASS" type="text">
    <input type="submit" name="Submit" value="Login">
</form>
```

`index.php`
```php
<?php
echo "Username:".$_GET["USER"]."</br>";
echo "Password:".$_GET["PASS"]."</br>";
?>
```

**VD**: Dùng link trực tiếp (không cần form)**:

```html
<a href="chitietsanpham.php?masp=12">Chi tiết sản phẩm</a>
```

```php
$masp = $_REQUEST["masp"]; // hoặc $_GET["masp"]
echo "Mã sản phẩm lấy được:".$masp;
```

- **Ưu điểm:** nhanh, có thể truyền không cần form, bookmark được.
- **Nhược điểm:** không bảo mật (dữ liệu hiện trên URL), giới hạn ~2048 ký tự.

# POST

**Đặc điểm**:
- Dữ liệu được **ẩn bên trong form**, không hiện trên URL.

**VD**:

```html
<form method="POST" action="thongtindangky.php">
    <input type="text" name="user">
    <input type="password" name="pass">
    <select name="gt">
        <option value="Nam">Nam</option>
        <option value="Nu">Nữ</option>
    </select>
    <input type="Submit" name="Submit" value="Đăng ký">
</form>
```

```php
<?php
	$user = $_POST["user"];
	$pass = $_POST["pass"];
	$gt   = $_POST["gt"];
	echo "Tên đăng nhập:".$user."<br>";
	echo "Mật khẩu đăng nhập:".$pass."<br>";
	echo "Giới tính:".$gt."<br>";
?>
```

- **Ưu điểm**: Bảo mật hơn GET, không giới hạn dung lượng dữ liệu.
- **Nhược điểm**: Chậm hơn GET, dễ lỗi khi bấm Back/Refresh (*form bị resubmit/expired,...*).

>[!Note]
>Cả GET và POST đều có thể dùng `$_REQUEST["controlName"]` để lấy dữ liệu bất kể được gửi theo cách nào.

# Cookie

**Đặc điểm**:
- Là 1 tập tin nhỏ được **server lưu xuống máy client**.
- Mỗi lần client gửi yêu cầu, cookie sẽ tự động được gửi kèm lên server.

**Ưu điểm**: Lưu được lâu dài (dù đóng browser), dùng lưu thông tin cá nhân.

**Nhược điểm**: Kém bảo mật (dữ liệu nằm ở máy client, dễ bị chỉnh sửa/tấn công), ảnh hưởng hiệu suất vì cookie luôn tự động gửi kèm mỗi request.

**Cú pháp**:
```php
// Thêm cookie
setcookie(name, value, expire, path, domain); // phải đặt trước thẻ <html>

// Xóa cookie (ghi đè cookie hiện có bằng "")
setcookie(name, "", time() - 3600);
```

**VD**:

`a.php`
```php
// Ghi cookie
<?php
	$t = "1111";
	setcookie("a", $t);
?>
<html>
	<body>
		Cookie value: <?php echo $t; ?>
		<a href="b.php">Go to b</a>
	</body>
</html>
```

`b.php`
```php
// Đọc cookie
<?php
	if (isset($_COOKIE['a']))
	    echo "Cookie value: " . $_COOKIE['a'];
	else
	    echo "Cookie value not found";
?>
```

# Session

**Đặc điểm**:
- Dữ liệu được **lưu trên server**.
- Mỗi client được cấp 1 định danh (session ID) duy nhất. Browser chỉ gửi session ID lên, server dựa vào đó lấy dữ liệu tương ứng.

**Ưu điểm**: Bảo mật hơn cookie (data không nằm ở client), không lo bị chặn như cookie.

**Nhược điểm**: Chỉ tồn tại trong 1 phiên làm việc (đóng browser hoặc hết hạn là mất).

**Cú pháp:**
```php
session_start(); // bắt buộc đặt trước thẻ <html>
$_SESSION["sessionVar"] = $value;   // ghi
echo $_SESSION["sessionVar"];       // đọc
unset($_SESSION["sessionVar"]);     // hủy 1 biến
session_destroy();                  // hủy cả session
```

**VD**:

`SessionA.php`
```php
<?php
	session_start();
	$_SESSION['username'] = 'guest';
	$_SESSION['password'] = '12345';
?>
<html>
	<body>
	<a href="SessionB.php">Go to session B</a>
	</body>
</html>
```

`SessionB.php`
```php
<?php
	session_start();
?>
<html>
	<body>
		username = <?php echo $_SESSION['username']; ?>
		<br>
		password = <?php echo $_SESSION['password']; ?>
	</body>
</html>
```
