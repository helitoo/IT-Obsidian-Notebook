Apache Hadoop là một framework, mã nguồn mở, dựa trên Java, cho phép lưu trữ và xử lý các tập dữ liệu lớn trên các cụm máy tính phân tán.

Hadoop gồm 4 module cốt lõi:
- **HDFS (Hadoop Distributed File System)**: Hệ thống tệp phân tán giúp chia nhỏ tệp dữ liệu lớn và phân phối chúng trên nhiều máy tính.
- **MapReduce**: Mô hình lập trình và khung xử lý tính toán song song trên các tập dữ liệu phân tán.
- **YARN (Yet Another Resource Negotiator)**: Quản lý tài nguyên cụm và lên lịch cho các tác vụ của người dùng.
- **Hadoop Common**: Các thư viện và tiện ích Java hỗ trợ các mô-đun khác.
