# Giới thiệu

**Spark**:
- Là một hệ thống tính toán mã nguồn mở phục vụ cho xử lý dữ liệu.
- Spark hỗ trợ:
	- Phân phối dữ liệu vào các cụm (*cluster distributing*), xử lý song song (*parallel*) và *catching* -> Giúp xử lý một lượng khổng lồ dữ liệu với hiệu năng cao.
	- Xử lý dữ liệu theo thời gian thực (*real-time processing*).
	- Có cơ chế sao lưu và phục hồi.
	- Tích hợp được nhiều nguồn dữ liệu và công nghệ xử lý dữ liệu khác nhau, kể cả *machine learning, graph processing và streaming analytics*.
	- Hỗ trợ nhiều loại ngôn ngữ lập trình (thông qua các *API*) như *Python, Java, Scala, R*.

Sự khác biệt cốt lõi của Spark so với [[1. Giới thiệu Apache Hadoop|Apache Hadoop]] là khả năng xử lý dữ liệu trên RAM thay vì đĩa nhớ, giúp tối ưu tốc độ xử lý của hệ thống.

Bài viết này sẽ nói về API của Python là **PySpark**.

# Một số thuật ngữ được dùng trong Spark

| Thuật ngữ                         | Ý nghĩa                                                                                                                                                                      |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Application**<br>(Ứng dụng)     | Chương trình do người dùng viết trên Spark, gồm một Driver và các Executor chạy trên cụm máy.                                                                                |
| **Driver**                        | Nút khởi chạy của Spark và bắt đầu một `SparkSession`. Đóng vai trò bộ não điều phối các hoạt động tính toán, **không** tự thực hiện tính toán (*filter, map, reduce,...*).  |
| **Master**                        | Nút điều khiển phân tán các cụm của Spark, nó nắm giữ *Cluster manager* là chương trình quản lý tài nguyên cụm *Standalone, Mesos, YARN,...*).                               |
| **Cluster**<br>(Cụm)              | Nhóm các nút (JVM) kết nối với nhau, mỗi nút chạy Spark với vai trò điều khiển (driver) hoặc tính toán (worker).                                                             |
| **Worker**                        | Nút thực thi xử lý dữ liệu, nắm giữ *Excuter*.                                                                                                                               |
| **Executor**<br>(Đơn vị thực thi) | Tiến trình chạy trên nút worker, xử lý dữ liệu trong bộ nhớ/ổ đĩa. Mỗi ứng dụng có Executor riêng.                                                                           |
| **Job**<br>(Công việc)            | Chuỗi tính toán song song gồm nhiều Stage, được kích hoạt bởi một **action** (*`count()`, `collect()`, `save()`, `read()`, `write()`,...*).                                  |
| **Stage**<br>(Nhóm tác vụ)        | Tập các tác vụ có thể chạy liên tiếp mà **không cần shuffle** (VD: *`read()` → `map()` → `filter()`*). Ranh giới giữa các Stage là các thao tác shuffle.                     |
| **Task**<br>(Tác vụ)              | Đơn vị công việc nhỏ nhất: một thao tác (*map, filter,...*) áp dụng cho **một partition**, chạy bằng một luồng trong Executor. VD: 2 partition → `filter()` sinh ra 2 Task.  |
| **Shuffle**<br>(Xáo trộn)         | Thao tác phân vùng lại dữ liệu giữa các nút trong cụm. `join` và các thao tác kết thúc bằng `ByKey` sẽ kích hoạt shuffle. **Tốn kém** vì phải truyền nhiều dữ liệu qua mạng. |
| **Partition**<br>(Phân vùng)      | Mảnh dữ liệu logic của RDD/Dataset. Mỗi partition do một core của Executor xử lý, giúp chạy song song. VD: 4 partition + 4 core → xử lý cùng lúc cả 4.                       |

# Kiến trúc của Spark

Spark gồm các thành phần nòng cốt sau:
- **Spark SQL**: Cho phép kết hợp các truy vấn SQL / HiveSQL vào Spark.
	- Có thể kết nối với bất kỳ nguồn dữ liệu nào với phương thức giống nhau.
	- Có thể kết nối với các công cụ bên ngoài (*ODBC, JDBC,...*).
- **Spark Structured Streaming**: Cho phép xử lý dữ liệu realtime (Xử lý liên tục - (Continuous processing) dựa trên Spark SQL và Dataset/Dataframe API.
- **MLlib**: Bao gồm các thư viện machine learning, có thể lắp ghép thành một ML pipeline hoàn chỉnh.
- **GraphX**: Xử lý và phân tích dữ liệu đồ thị.

**2 - Tải Apache Spark** [tại đây](https://spark.apache.org/downloads.html). Giả sử lưu folder này tại `C:\Users\Admin\Documents\Spark`.

**3 - Tải PySpark và JupyterLab**:

```sh
pip install pyspark
pip install findspark
pip install jupyterlab
```

**4 - Cài đặt các biến môi trường cho PySpark**:

| Field                        | Value                            |
| ---------------------------- | -------------------------------- |
| `SPARK_HOME`                 | `C:\Users\Admin\Documents\Spark` |
| `PYSPARK_DRIVER_PYTHON`      | `jupyter`                        |
| `PYSPARK_DRIVER_PYTHON_OPTS` | `lab`                            |
| `PYSPARK_PYTHON`             | `python`                         |

Chạy thử Jupyterlab:
```sh
jupyter-lab
```

```python
from pyspark.sql import SparkSession

spark = SparkSession.builder \
    .appName('Test') \
    .config("spark.sql.execution.pyspark.udf.faulthandler.enabled", "true") \
    .config("spark.python.worker.faulthandler.enabled", "true") \
    .getOrCreate()

data = [('Alice', 25), ('Bob', 30), ('Charles', 35)]
df = spark.createDataFrame(data, ['Name', 'Age'])
df.show()
```
