
![](https://upload.wikimedia.org/wikipedia/commons/3/38/Hadoop_logo_new.svg?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=original)

Apache Hadoop là một framework, mã nguồn mở, dựa trên Java, cho phép lưu trữ và xử lý các tập dữ liệu lớn trên các cụm máy tính phân tán.

**Hadoop gồm 4 module cốt lõi**:
- **HDFS (Hadoop Distributed File System)**: Hệ thống tệp phân tán giúp chia nhỏ tệp dữ liệu lớn và phân phối chúng trên nhiều máy tính.
- **MapReduce**: Mô hình lập trình và khung xử lý tính toán song song trên các tập dữ liệu phân tán.
- **YARN (Yet Another Resource Negotiator)**: Quản lý tài nguyên cụm và lên lịch cho các tác vụ của người dùng.
- **Hadoop Common**: Các thư viện và tiện ích Java hỗ trợ các mô-đun khác.

**Một số hạn chế của Hadoop và mô hình MapReduce**:
- **Khả năng lập trình hạn chế**: Framework ép các script phải tuân theo kiến trúc MapReduce khá rườm rà, gượng ép và phức tạp. Thiếu các tính năng nâng cao như lọc, kết, hội, giao,... Ngoài ra cũng không hỗ trợ các ngôn ngữ ngoài Java một cách đầy đủ.
- **Tốc độ**: Dữ liệu lưu trên đĩa bị tốn thời gian đọc/ghi từ/vào đĩa, không phù hợp với các bài toán có tính tuần hoàn, realtime hoặc machine learning training.

Từ những hạn chế này, người ta đã nghĩ ra [[1. Giới thiệu Apache Spark và PySpark|Apache Spark]].
