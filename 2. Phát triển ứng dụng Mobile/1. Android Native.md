# Android

### Giới thiệu

Android là một hệ điều hành mở, hoạt động trên các thiết bị di động (bao gồm cả TV, ô tô,...) dựa trên nhân Linux.

**Chức năng**:
- Hỗ trợ các thao tác về chạm (Tough gestures): Vuốt (swipping), Chạm (tapping), Chụm (Pinching).
- Hỗ trợ bàn phím ảo (Virtual keyboard).
- Hỗ trợ Bluetooth, USB,...

**Sensor**:
- Dùng để phát hiện hành vi của người dùng và phản hồi.
- Những hành vi này không nhất thiết phải tương tác với thiết bị.

**Android app**:
- Là tập hợp của các giao diện có thể được tương tác, chạy trên Android.
- Được viết bằng Java và XML.
- Được phát triển thông qua Android Software Developer Kit (SDK).
- Được thực thi bởi Anroid Runtime Virtual machine (ART).

### Kiến trúc Android

1. **System apps and User apps**: Các ứng dụng hệ thống và ứng dụng người dùng.
2. **Java API Framework**: Cung cấp cách thức để sử dụng các tính năng của Android (API). Các API này được viết bằng Java. Ở tầng sâu hơn các API này là các thư viện được viết bằng C/C++.
3. **Hardware abstraction layer (HAL)**: Các interface chuẩn đại diện cho các thiết bị phần cứng.
4. **Linux kernel**: Nhân Linux làm lõi.

# Phát triển ứng dụng Android

### Giới thiệu

**Android Software Developer Kit (Android SDK)**: Là bộ công cụ phát triển ứng dụng Android, gồm có các thành phần sau:
- **SDK Platform Tools**: Công cụ giao tiếp với thiết bị/emulator, không phụ thuộc phiên bản Android cụ thể.
	- **Android Debug Bridge (ADB)**: Cài app, xem log (`logcat`), shell vào thiết bị, forward port (`adb reverse`).
	- **Fastboot**: Flash firmware/partition khi thiết bị ở chế độ bootloader.
- **SDK Build Tools**: Công cụ để build app.
	- **aapt2**: Compile resource (*XML, hình ảnh...*) thành binary.
	- **d8/r8**: Chuyển bytecode Java/Kotlin (`.class`) thành *dex* và tối ưu/rút gọn code.
	- **zipalign, apksigner**: Căn chỉnh và ký APK.
- **SDK Platforms**: Mỗi phiên bản Android (API level) có 1 platform riêng, chứa `android.jar` (API framework để compile against) và system image thông tin. VD: `android-34` (*Android 14*), `android-35` (*Android 15*), bạn cần ít nhất 1 platform khớp với `compileSdkVersion`/`targetSdkVersion` trong project.
- **System Images**: Dùng để tạo AVD (*Android Virtual Device* hay *emulator*). Có nhiều biến thể:
	- Theo kiến trúc: `x86_64`, `arm64-v8a`,...
	- Theo loại: `Google APIs`, `Google Play` (có Play Store), `AOSP` (thuần, không Google service).
- **Emulator**: Chương trình chạy AVD (*giả lập thiết bị Android trên máy tính*), dùng ảo hoá phần cứng (KVM trên Linux, HAXM/Hypervisor.Framework trên Windows/macOS) để tăng tốc.

**Android Studio**: Là một IDE chính thức dành cho phát triển ứng dụng Android, đã có sẵn SDK rồi.

Xem hướng dẫn tải và lập trình ứng dụng Android Studio đầu tiên tại đây: [Setup Android Studio](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-2).
