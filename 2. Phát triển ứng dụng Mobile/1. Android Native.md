# Android

### Giới thiệu

Android là một hệ điều hành mở, hoạt động trên các thiết bị di động (bao gồm cả TV, ô tô,...) dựa trên nhân Linux.

**Chức năng**:
- Hỗ trợ các thao tác về chạm (Tough gestures): Vuốt (swipping), Chạm (tapping), Chụm (Pinching).
- Hỗ trợ bàn phím ảo (Virtual keyboard).
- Hỗ trợ Bluetooth, USB,...

**Sensor**:
- Dùng để phát hiện hành vi của người dùng và phản hồi.
- Những hành vi này không nhất thiết phải tương tác với thiết bị.

**Activity**:
- Mỗi activity tương ứng với một chức năng của ứng dụng.
- Mỗi ứng dụng có một activity chính là `MainActivity` (*Activity*) / `activity_main` (*Layout*). Đây là activity đầu tiên được kích hoạt khi khởi động ứng dụng. Các activity khác được gọi bởi activity chính.

**Android app**:
- Là tập hợp của các giao diện có thể được tương tác, chạy trên Android.
- Được viết bằng Java (logic) và XML (giao diện).
- Được phát triển thông qua Android Software Developer Kit (SDK) hoặc Android Native Developer Kit (NDK).
- Được thực thi bởi Anroid Runtime Virtual machine (ART).

### Kiến trúc Android

1. **System apps and User apps**: Các ứng dụng hệ thống và ứng dụng người dùng.
2. **Java API Framework**: Cung cấp cách thức để sử dụng các tính năng của Android (API). Các API này được viết bằng Java. Ở tầng sâu hơn các API này là các thư viện được viết bằng C/C++.
3. **Hardware abstraction layer (HAL)**: Các interface chuẩn đại diện cho các thiết bị phần cứng.
4. **Linux kernel**: Nhân Linux làm lõi.

# Phát triển ứng dụng Android

### Giới thiệu

**Android Software Developer Kit (Android SDK)**: Là bộ công cụ phát triển ứng dụng Android dựa trên Java/Kotlin, gồm có các thành phần sau:
- **SDK Platform Tools**: Công cụ giao tiếp với thiết bị/emulator, không phụ thuộc phiên bản Android cụ thể.
	- **Android Debug Bridge (ADB)**: Cài app, xem log (`logcat`), shell vào thiết bị, forward port (`adb reverse`).
	- **Fastboot**: Flash firmware/partition khi thiết bị ở chế độ bootloader.
- **SDK Build Tools**: Công cụ để build app.
	- **aapt2**: Compile resource (*XML, hình ảnh...*) thành binary.
	- **d8/r8**: Chuyển bytecode Java/Kotlin (`.class`) thành *dex* và tối ưu/rút gọn code.
	- **zipalign, apksigner**: Căn chỉnh và ký APK.
- **SDK Platforms**: Mỗi phiên bản Android (API level) có 1 platform riêng, chứa `android.jar` (API framework để compile against) và system image thông tin. VD: `android-34` (*Android 14*), `android-35` (*Android 15*), bạn cần ít nhất 1 platform khớp với `compileSdkVersion`/`targetSdkVersion` trong project.
- **System Images**: Dùng để tạo AVD (*Android Virtual Device* hay *emulator*). Có nhiều biến thể:
	- Theo kiến trúc: `x86_64`, `arm64-v8a`,...
	- Theo loại: `Google APIs`, `Google Play` (có Play Store), `AOSP` (thuần, không Google service).
- **Emulator**: Chương trình chạy AVD (*giả lập thiết bị Android trên máy tính*), dùng ảo hoá phần cứng (KVM trên Linux, HAXM/Hypervisor.Framework trên Windows/macOS) để tăng tốc.

**Android Native Developer Kit (Android NDK)**: Là bộ công cụ dựa trên C/C++, là mức thấp nhất để phát triển ứng dụng Android.

**Android Studio**: Là một IDE chính thức dành cho phát triển ứng dụng Android, đã có sẵn SDK rồi.

Xem hướng dẫn tải và lập trình ứng dụng Android Studio đầu tiên tại đây: [Setup Android Studio](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-2).

### Cấu trúc dự án Android

```
MyApp/
├── app/                          # Module chính của ứng dụng
│   ├── manifests/
│   │   └── AndroidManifest.xml   # Khai báo Activity, Permission, Service...
│   ├── java/ (hoặc kotlin+java)
│   │   └── com.example.myapp/
│   │       ├── MainActivity.kt
│   │       ├── adapters/
│   │       ├── models/
│   │       └── viewmodels/
│   ├── res/
│   │   ├── layout/
│   │   ├── drawable/
│   │   └── values/
│   │   ├── mipmap/
│   └── build.gradle (Module: app)
├── build.gradle (Project)
├── settings.gradle
└── gradle.properties
```

- `AndroidManifest.xml`: Khai báo Activity, Service, Permission, thông tin app,...
- `java/`/`kotlin+java/`: Chứa toàn bộ mã nguồn logic (Activity, Fragment, ViewModel, Repository,...).
- `res/`: Chứa các tài nguyên tĩnh của ứng dụng, có một số folder thường dùng là:
	- `layout/`: Định nghĩa giao diện (View, ViewGroup) bằng XML.
	- `drawable/`: Các icon dùng trong ứng dụng.
	- `values/`: Hằng số dùng chung: text, màu, kích thước, theme,...
	- `mipmap/`: Các icon đại diện cho toàn bộ ứng dụng (favicon).

### Luồng hoạt động

1. **Tìm `MainActivity`**: Hệ thống đọc `AndroidManifest.xml` để tìm Activity có `intent-filter` là `MAIN` + `LAUNCHER` → đây là Activity khởi chạy đầu tiên (thường là `MainActivity`).
2. **Khởi động vòng đời Activity**:
	1. `onCreate()`: gọi `setContentView(R.layout.activity_main)` để nạp giao diện từ file XML trong `res/layout`.
	2. Hệ thống **inflate** (chuyển XML thành cây đối tượng `View`/`ViewGroup` trong bộ nhớ).
3. **Gắn kết logic với giao diện**:
	- Dùng `findViewById()` hoặc **View Binding/Data Binding** để lấy tham chiếu tới các View.
	- Gán sự kiện (click listener...), gán dữ liệu (Adapter cho RecyclerView, ViewModel cho MVVM...).
4. **Hiển thị lên màn hình**: View được vẽ (draw) lên `Window` thông qua `ViewRootImpl` → xuống tầng hệ thống để render pixel thật.
5. **Tương tác người dùng**: Người dùng chạm/click → sự kiện được truyền từ hệ thống → `Activity` → `ViewGroup` → `View` cụ thể xử lý (theo cơ chế event dispatch: `dispatchTouchEvent` → `onInterceptTouchEvent` → `onTouchEvent`).
6. **Chuyển sang activity tiếp theo**: Chuyển Activity khác bằng `Intent` → Activity cũ vào `onPause()` → `onStop()` (có thể `onDestroy()` nếu hệ thống thu hồi bộ nhớ).

### Thành phần giao diện

**Views**:
- `View` là lớp cơ sở (base class) cho hầu hết các thành phần giao diện trên Android.
- `View` có thể được định nghĩa bằng XML hoặc mã Java.

Có một số loại `View` sau:
- `TextView`: Hiển thị văn bản, không chỉnh sửa được.
- `EditText`: Chỉnh sửa văn bản.
- `ImageView`: Hình ảnh.
- `Button`.
- `CheckBox`.
- `RadioButton`.
- `Switch`.
- `Slider`: Thanh kéo chọn giá trị.
- `ScrollView`, `RecyclerView`: View có thanh cuộn, dùng để chứa nội dung dài.
- `LinearLayout`, `ConstraintLayout`: Gôm nhóm và bố trí các view (Group), mỗi group có một đặc điểm riêng dựa vào cách sắp xếp các view con của nó.

View có một số thuộc tính sau:
- `color`.
- `dimension`: Kích thước.
- `position`.
- `visible`: Khả năng hiển thị của view.
- Các thuộc tính quy định tương tác của người dùng với view.
- Các thuộc tính quy định quan hệ với các view khác.

Quy tắc đặt tên thuộc tính:
- Gán trực tiếp giá trị: `android:propertyName="propertyValue"`.
- Gán giá trị trong resource: `android:propertyName="resourceName/resourceValue"`.
