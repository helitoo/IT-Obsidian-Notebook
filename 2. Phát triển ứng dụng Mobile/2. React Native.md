# Giới thiệu

### React Native

React Native là một framework phát triển ứng dụng mobile, bao gồm iOS và Android, với hệ thống API tương tự React trong phát triển ứng dụng web.

>[!question] React Native có phải cũng chạy một browser bên trong như Electron không?
>- Khác với Electron, React Native không bao gồm browser engine (như Chromium) bên trong nó.
>- Mã JS/TS của React Native có thể tương tác trực tiếp với mobile thông qua cơ chế **JSI (JS Interface)**. Nên React Native không kế thừa toàn bộ các API của React, mà có thêm các API đặc thù của mobile.

### Expo

**Expo** là một framework cấp cao hơn React Native, bao bọc React Native. Nó bao gồm môi trường phát triển, routing, build, deploy.

**EAS (Expo Application Service)** là 1 dịch vụ của Expo, cho phép biên dịch ứng dụng mobile trên cloud một cách runtime, cũng như cung cấp các phương thức publish ứng dụng trên Google Play / AppStore.

>[!note]
>React Native chỉ là phần động cơ. Expo là chiếc xe hơi chạy bằng động cơ đó.

##### Development Build (Dev Client)

Là bản build native riêng của app bạn.

**Điều kiện sử dụng:**
- Cần **build một lần** để tạo file cài đặt (`.apk`/`.ipa`) rồi cài vào máy/emulator. Đối với máy điện thoại Android, cần mở chế độ **USB Debugging** (*Gỡ lỗi qua USB*) và kết nối với máy tính qua cáp USB, ngoài ra trên máy tính cũng cần tải thêm **Android SDK**.
- Bắt buộc khi dự án có native module không nằm trong Expo Go, hoặc có config plugin tùy chỉnh

**Cách dùng:**
```bash
# B1: cài package
npx expo install expo-dev-client

# B2: build (chọn 1 trong 2 cách)
eas build --profile development --platform android   # build trên cloud (EAS)
# hoặc
npx expo run:android   # build local, cần Android Studio/SDK, yarn android
npx expo run:ios       # build local, cần Xcode (chỉ macOS),  yarn ios

# B3: chạy dev server, app dev build sẽ tự kết nối
npx expo start --dev-client
```

>[!important] Kiểm tra phiên bản Java
>React Native hiện hỗ trợ tốt nhất ở phiên bản **JDK 17**. Hãy xem hướng dẫn cài đặt JDK [[1. Giới thiệu & Cài đặt Java SE|tại đây]].

>[!important] Đăng ký environment variable cho Android SDK Platform tools và emulator
>Khi tải Android Studio thì SDK đã có sẵn tại `C:\Users\Admin\AppData\Local\Android\Sdk` rồi. Bạn cần đăng ký một *System variable* tên là **`ANDROID_HOME`** trỏ tới địa chỉ trên. Sau đó đưa `%ANDROID_HOME%\platform-tools` và `%ANDROID_HOME%\emulator` vào `Path` của *System variables*.

**Quy trình đằng sau `expo run:android`**:
- **Prebuild** (*nếu chưa có folder `android/`*): Expo sinh code native (Gradle project, Manifest, gradle files) từ cấu hình trong `app.json`/`app.config.js` và các plugin.
- **Gradle build** (*bước tốn thời gian nhất*): Gradle resolve dependencies (*thư viện native, autolinking các module RN*), compile resource (AAPT2), compile Java/Kotlin, nếu có code C++/NDK thì compile luôn, sau đó dex hoá (D8) và đóng gói thành `.apk`, ký (sign) bằng debug keystore.
- **Cài đặt qua ADB**: APK được cài lên thiết bị/emulator qua `adb install`.
- **Khởi động Metro bundler**: Metro (JS bundler) chạy dev server trên máy tính, bundle JS/TS (transform bằng Babel, resolve module) theo kiểu on-demand.
- **Kết nối app ↔ Metro**: `adb reverse tcp:8081 tcp:8081` được thiết lập để app trên thiết bị (qua USB) gọi vào Metro server trên máy tính lấy JS bundle, sau đó app khởi chạy và load bundle.

>[!question] Khi Metro đang chạy, sửa code có cập nhật runtime không?
>Metro có chức năng **Fast refresh**, tự động cập nhật UI khi code thay đổi gần như ngay lập tức mà không cần rebuild native hay cài lại `.apk`. Lưu ý Fast refresh không áp dụng cho các trường hợp thay đổi native, thay đổi thư viện và cấu hình app.

>[!question] Khi ngắt USB thì sao?
>- **App đang chạy vẫn hoạt động bình thường** vì JS bundle đã được load vào bộ nhớ của app rồi, không phụ thuộc kết nối để chạy tiếp.
>- Tuy nhiên, ngắt USB sẽ làm **mất kết nối tới Metro** → Fast Refresh không hoạt động.
>- **Khi cắm lại USB**: kết nối ADB được thiết lập lại, nhưng bạn thường cần Metro/CLI tự động chạy lại `adb reverse tcp:8081 tcp:8081` (*Expo CLI/RN CLI thường tự làm việc này khi phát hiện thiết bị mới kết nối, hoặc bạn có thể chạy tay*). Sau đó reload lại app là kết nối lại được với Metro bình thường.

##### Expo Go

**Expo Go** là 1 app có sẵn tải từ App Store / Google Play, đóng vai trò như "sandbox" chạy thử code JS của bạn mà không cần build native.

- Dự án **không được** dùng native module ngoài danh sách các module đã tích hợp sẵn trong Expo Go (*không dùng config plugin tùy chỉnh, không thêm native code riêng,...*)

**Cách dùng:**

# Styling

### `StyleSheet.create`

Bạn sẽ tạo 1 object quy định các style thông qua phương thức `StyleSheet.create` với cú pháp tương tự React, sau đó tiêm vào component thông qua thuộc tính `.style`.

**VD**:
```jsx
import { View, Text, StyleSheet } from 'react-native';

export default function Card() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Xin chào</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 16,
    borderRadius: 12,
    backgroundColor: '#ffffff',
    shadowColor: '#000',
    shadowOpacity: 0.1,
    shadowRadius: 8,
  },
  title: {
    fontSize: 18,
    fontWeight: '600',
    color: '#111827',
  },
});
```

### Nativewind

**Nativewind** là một thư viện tương tự như TailwindCSS nhưng dành cho Native React.

Xem hướng dẫn cài đặt [tại đây](https://www.nativewind.dev/docs/getting-started/installation).

**Nhược điểm:**
- Phải cài thêm dependency, cấu hình Babel/Metro.
- Một số thuộc tính RN đặc thù (*`shadowColor`, animation,...*) không map 1:1 với class Tailwind → vẫn phải fallback về style object.
- className string dài có thể khó đọc nếu style phức tạp.

```jsx
export default function Card() {
  return (

      <Text className="text-lg font-semibold text-gray-900">

  );
}
```

# Routing và Navigation

**Expo routing** cũng có nguyên lý tương tự như [[2.1. Routing & Navigation|NextJS Routing]], địa chỉ của file  cũng là địa chỉ routing (*file-based*).

### Navigation

**Cách 1**: Dùng component `Link` với thuộc tính `href`:
```tsx
import { Link } from 'expo-router';
import { View, Text } from 'react-native';

export default function HomeScreen() {
  return (
    <View>
      {/* Điều hướng đơn giản */}
      <Link href="/about">
        <Text>Đến trang About</Text>
      </Link>

      {/* Điều hướng kèm params, dùng object href */}
      <Link
        href={{
          pathname: '/users/[id]',
          params: { id: '42' },
        }}
      >
        <Text>Xem user 42</Text>
      </Link>

      {/* Dùng asChild để custom style nút bấm */}
      <Link href="/settings" asChild>
        <TouchableOpacity>
          <Text>Cài đặt</Text>
        </TouchableOpacity>
      </Link>
    </View>
  );
}
```


**Cách 2**: Dùng `useRouter`:

```tsx
// Lấy ra router từ hook
const router = useRouter();
```

Router có một số method sau:

|Method|Ý nghĩa|
|---|---|
|`router.push('/path')`|Đẩy thêm route mới vào stack (có thể back)|
|`router.replace('/path')`|Thay route hiện tại (không back được về route cũ)|
|`router.back()`|Quay lại màn hình trước|
|`router.setParams({...})`|Cập nhật params của route hiện tại|
|`router.canGoBack()`|Kiểm tra có thể back hay không|

>[!tip] So sánh `Link` và `useRouter`
>- `Link` mặc định tương đương với `.push`.
>- Để `Link` tương đương `replace`, hãy thêm boolean attribute **`replace`** vào `Link`.
>- Các method `.push`, `.replace` đều có thuộc tính `pathName` và `params` giống `Link`.


>[!question] Vì sao không truyền thẳng params vào `pathName` mà phải truyền qua `params`
>- Thuộc tính `params` đã có sẵn các chức năng encodeURI. Bạn có thể truyền params vào `pathName` nhưng phải tự encode.
>- Trong Expo routing gần như không phân biệt segment params và query params, tất cả đều khai báo trong thuộc tính `params`.

### Expo router

Mỗi trang là 1 file `.jsx`/`.tsx`.

**VD**:
```
app/
  index.tsx        → "/"
  about.tsx        → "/about"
  settings.tsx     → "/settings"
```

### Expo group

Dùng ngoặc đơn `(groupName)` để đặt tên thư mục nhóm các route lại với nhau **mà không ảnh hưởng đến URL**. Thường dùng để:
- Tổ chức code theo nhóm chức năng (auth, tabs, ...)
- Áp dụng layout riêng cho từng nhóm (ví dụ nhóm có tab bar, nhóm không có).

**VD**:
```
app/
  (auth)/
    login.tsx      → "/login"   (KHÔNG phải "/(auth)/login")
    register.tsx   → "/register"
  (tabs)/
    _layout.tsx
    home.tsx        → "/home"
    profile.tsx      → "/profile"
```

### Dynamic routing

Dùng dấu ngoặc vuông **`[param]`** trong tên file để tạo route động - nhận giá trị biến vào path.

**VD**:
```
app/
  users/
    [id].tsx       → "/users/1", "/users/abc", ...
  posts/
    [...slug].tsx  → route "catch-all" nhiều đoạn: "/posts/a/b/c"
```

`app/users/[id].tsx`
```tsx
import { View, Text } from 'react-native';
import { useLocalSearchParams } from 'expo-router';

export default function UserDetailScreen() {
  const { id } = useLocalSearchParams<{ id: string }>();

  return (
    <View>
      <Text>ID: {id}</Text>
    </View>
  );
}
```

`app/posts/[...slug].tsx`
```tsx
import { View, Text } from 'react-native';
import { useLocalSearchParams } from 'expo-router';

export default function PostScreen() {
  const { slug } = useLocalSearchParams<{ slug: string[] }>();
  // "/posts/2024/08/hello" => slug = ["2024", "08", "hello"]

  return (
    <View>
      <Text>Slug: {slug?.join('/')}</Text>
    </View>
  );
}
```

### Query params

Dùng hook **`useLocalSearchParams()`** để đọc **cả dynamic params lẫn query params**.

>[!tip]
>- **`useLocalSearchParams`**: Bắt được các params ở trang hiện tại.
>- **`useGlobalSearchParams`**: Bắt được params ở mọi trang. (trang cha hoặc con).

**VD**:

Điều hướng đến trang:
```tsx
<Link href="/search?keyword=react-native&sort=asc">
  Tìm kiếm
</Link>
```

Nhận params:
```tsx
import { View, Text } from 'react-native';
import { useLocalSearchParams } from 'expo-router';

export default function SearchScreen() {
  const { keyword, sort } = useLocalSearchParams<{
    keyword?: string;
    sort?: string;
  }>();

  return (
    <View>
      <Text>Từ khóa: {keyword}</Text>
      <Text>Sắp xếp: {sort}</Text>
    </View>
  );
}
```

